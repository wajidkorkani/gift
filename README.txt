# Love Website ❤️

A romantic interactive single-page website inspired by the reference video.

## Run
Just open `index.html` in a browser.

## Personalize
Open `index.html` and change:
- `Jaan` → your person's name
- The messages/questions
- Button labels

Open `script.js` and change:
- `const startDate = new Date();`
  to your real relationship/start date, for example:
  `const startDate = new Date("2026-02-14T00:00:00");`

No backend or installation is required.
